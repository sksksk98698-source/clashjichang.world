## 📖 项目简介 (Overview)

**`clashjichang.world`（Clash 机场）** 是一个基于 **Astro 7 + Tailwind CSS 4** 构建的高性能、纯静态预渲染（SSG）跨境网络评测导航与工程知识库。

本项目致力于解决传统评测站“参数虚标、缺乏原图实证、同质化薄内容、客户端下载渠道不安全”四大痛点，通过 **42 家主流机场结构化数据库**、**17 份 `MAI-TEST-BOT` 原始无修测速长图** 以及 **7 大超万字（10,600–15,700 纯汉字）专著级工程专题**，为用户提供兼具搜索深度（SEO）与生成式 AI 引擎友好度（GEO）的决策指南。

- **严谨的 Schema.org JSON-LD 矩阵**：

## 🚀 快速开始 (Getting Started)

### 1. 环境要求
- **Node.js**: `>= 20.0.0`
- **包管理器**: `npm`

### 2. 安装依赖与本地开发

```bash
# 安装项目依赖
npm install

# 启动本地热更新开发服务器 (默认 http://localhost:4321)
npm run dev
```

### 3. 生产环境静态构建与预览

```bash
# 执行生产级静态编译 (输出至 dist/ 目录，共 59 个静态产物)
npm run build

# 本地预览编译后的静态站点
npm run preview
```

## ⚙️ 环境变量与站长平台接入 (Environment Variables)

复制 `.env.example` 为 `.env`（或在 Cloudflare Pages / Vercel 部署后台配置环境变量），即可在构建时将各大搜索引擎的验证 Meta 标签直接编译进全站 HTML `<head>`：

```ini
# Google Search Console HTML 标签验证
PUBLIC_GOOGLE_SITE_VERIFICATION=

# Bing Webmaster Tools HTML 标签验证 (msvalidate.01)
PUBLIC_BING_SITE_VERIFICATION=

# 神马搜索 / UC / 夸克站长平台验证 (shenma-site-verification)
PUBLIC_SHENMA_SITE_VERIFICATION=

# 百度搜索资源平台验证 (baidu-site-verification)
PUBLIC_BAIDU_SITE_VERIFICATION=

# Google Analytics 4 统计 ID (可选，如 G-XXXXXXXXXX)
PUBLIC_GA_ID=
```
